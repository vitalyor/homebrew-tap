# Homebrew tap for Cooldown

**English** · [Русский](#русский)

[Cooldown](https://github.com/vitalyor/cooldown) — Codex and Claude limits in the macOS menu bar,
what each agent is doing, and continuing work after a limit resets.

```sh
brew install --cask vitalyor/tap/cooldown
```

Cooldown is signed with a Developer ID certificate and notarized by Apple. It updates itself;
`brew upgrade` works too.
